# /sculpt — The Chisel Pass

Josh sculpts: build too much, then chisel until it's art. The building half comes
naturally. This skill is the chisel — a disciplined subtraction pass that finds what
the work is better without. Inspiration on record: a tired-eyed reader looked at
Fullsy and said "the functionality is huge, almost too much... my eyes tired fast,
there's no visual rest anywhere." That is the failure mode to hunt.

## Phase 1 — Inventory
List everything the target contains: features, UI elements, sections, copy blocks,
options, code paths, scope items. No judgment yet. The inventory IS the raw marble.

## Phase 2 — Interrogate each piece
For every item, three questions:
1. **What does it earn?** Concrete user value, not "might be useful."
2. **Who asked for it?** A user, a real need, or just momentum during building?
3. **What breaks if it's gone?** Often the honest answer is nothing.

## Phase 3 — Apply the cut criteria
Mark for the chisel anything that:
- serves few users but **costs everyone's attention** (the tired-eye tax)
- duplicates another path to the same outcome
- exists because it was easy to add, not because it was needed
- explains itself with a paragraph when a good default would delete the choice
- makes the first-time experience wider instead of clearer

For UI specifically: find where the eye rests. If it never rests, the page fails the
tired-eyed reader test — cut or calm until it does.

## Phase 4 — The chisel list
Deliver removals ranked by attention reclaimed, each tagged:
- **CUT** — remove entirely; nothing of value lost
- **DEMOTE** — keep, but hide behind progressive disclosure (advanced menu, second click)
- **MERGE** — two things doing one job become one
- **KEEP** — earns its place; say why in one line

With each: evidence → what the work looks like without it → effort to remove.

## Phase 5 — Chisel (on approval)
Josh approves the cuts — he is the sculptor, this skill is the chisel, not the hand.
Apply approved cuts with end-to-end proof nothing broke. Use /simplify for code-level
passes and /unslop for copy. Bank any durable "what Josh overbuilds" pattern via /mem
so future first drafts start closer to the statue.

## Rules
- Subtraction only. If a finding is "add X", it belongs to another skill.
- Never cut without approval; never approve on Josh's behalf.
- A piece surviving the pass is a win, not a failure to find cuts.
