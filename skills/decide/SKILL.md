# /decide — Decision Memo

For decisions with real stakes: pricing, partnerships, pivots, spend, positioning.
Structured multi-perspective analysis that ends in a memo, not an action.

## Phase 1 — Frame it
State the decision as a choice between named options (including "do nothing").
What's reversible about each? One-way doors get flagged — they deserve the full pass;
two-way doors get a faster, lighter one.

## Phase 2 — The board
/advisors (PRISM) on the decision: nine expert lenses, agreement map, /100 score.
For operator-flavored challenges (offer, pricing, funnel), route through the
Billion-Dollar Board consult instead.

## Phase 3 — The game
Pull the 2-3 relevant game-theory specialists — /first-mover-analyst for timing,
/credibility-assessor for counterparty claims, /market-competition-modeler for
competitive response, /commitment-device-engineer for follow-through design.
Only the ones that fit; no specialist parade.

## Phase 4 — Devil's advocate
One dedicated pass whose only job is the strongest case AGAINST the emerging
recommendation. Real steelman with evidence, not a token objection.

## Phase 5 — The memo
One page, no more:
- **Recommendation** — one sentence, with confidence level.
- **The three things that matter** — the load-bearing facts or assumptions.
- **What would change the answer** — the observable trigger for revisiting.
- **Dissent** — the devil's advocate case, honestly summarized.

## Rules
- Advise, don't execute. The memo ends the skill; action starts only on Josh's call.
- Assumptions labeled as assumptions. VALIDATE, DON'T THEORIZE applies to the inputs —
  verify the facts the memo leans on.
- If the decision reduces to money Josh could lose, show the worst case in dollars.
